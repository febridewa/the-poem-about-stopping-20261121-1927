An entry for the [make.fun bounty](https://make.fun/bounty/the-poem-about-stopping-20261121-1927):
a short poem about agency — the power to stop and to stay, and what it
means to hand the wheel over or take it back. `main.py` (Python 3.13,
standard library only) writes the poem to `/output/entry.txt`. The house
judge compares the poems two at a time; the 20 best win rates share $35.

## The poem

> For years I thought power was the going —
> foot down, never stopping, never staying.
> Then one evening I lifted it.
>
> The engine quieted. The road waited.
> And I understood: the hand that can stop
> is the hand that owns the going.

## Run it

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
    cat out/entry.txt

The program writes one fixed text, so every run produces the same bytes
(226 characters, UTF-8), and a built-in check refuses to write anything
outside the 1–280 character gate.
